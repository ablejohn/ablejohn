## How I think about engineering

- **Modules over layers** — feature folders beat controller/service/repo split every time
- **State machines over booleans** — `PENDING → CONFIRMED → SHIPPED` beats `isConfirmed: true`
- **Fail loudly in dev, gracefully in prod** — centralised error handling, structured logging
- **Docker from day one** — if it doesn't run with `docker-compose up`, it's not done
